# Cups & Caps Design — Light Theme Studio

Bespoke drinkware and premium headwear design studio in an editorial, warm light-theme template.

## Features
- **Light Theme Design System**: Warm alabaster, crisp porcelain, artisanal terracotta, and deep charcoal.
- **Dedicated 2D/3D Mockup Synthesizer**: Photorealistic ceramic mugs, insulated travel tumblers, vintage washed dad hats, retro mesh trucker caps, campfire enamel mugs, and fisherman beanies.
- **Interactive Live Studio**: Curved/arched text, custom font picker, stock heritage emblems, logo upload, 3D puff embroidery, and laser etching simulation.
- **Instant Tiered Bulk Quote Calculator**: Real-time volume discounting, setup fee waiver calculation, and packaging upgrades.
- **Brand Lookbook & Templates**: Pre-configured designs for cafes, streetwear brands, breweries, and outdoor clubs.
- **Slide-Over Shopping Cart**: Full order summary with promo code engine (`LIGHT15` for 15% off).

## Quick Launch
- **macOS**: Double-click `start_site_mac.command` (runs on `http://localhost:8001`)
- **Windows**: Double-click `start_site_windows.bat`
- **Linux**: Run `./start_site_linux.sh`
- **Direct Terminal**:
  ```bash
  python3 -m http.server 8001
  ```
